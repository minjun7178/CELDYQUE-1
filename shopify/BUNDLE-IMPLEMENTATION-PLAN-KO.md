# CELDYQUÉ Shopify 묶음·세트 구현 계획

작성일: 2026-11-18 · 상태: 조사 후 제안, 미구현 · 대상: `celdyque-dev-test.myshopify.com`만

[전체 Amazon 조사표](AMAZON-STORE-AUDIT-2026-11-18-KO.md)를 기준으로 작성했습니다. 기존 홈페이지와 main은 유지합니다. 현재 작업 브랜치 `codex/shopify-liquid-pilot`과 기존 worktree를 계속 사용하며, 운영 저장소 전체를 다시 복사할 필요는 없습니다.

## 목표와 범위

기존 디자인 안에서 고객이 **단품 / 2-Pack / 정해진 세트**를 고르고, 선택한 구성의 이미지·설명·가격을 확인한 다음 Shopify 장바구니와 결제로 이어지도록 합니다.

- 기존 단품 14개 유지.
- 추가 묶음 5개 + 혼합 세트 8개 = **추가 판매 구성 13개**를 검토·등록.
- Retinal Eye Cream은 현재 판매 불가이므로 판매 재개 여부 확인 전 제외.
- Amazon의 판매 구성과 가격을 맞추는 것이 목표입니다. Prime 혜택·정기구독·쿠폰·“2개 구매 10% 할인”은 별도 프로그램이므로 이번 고정 세트 구현에 자동 포함하지 않습니다.
- 기존 승인 단품 가격은 유지합니다. 신규 13개 가격은 조사값이며, 등록 전에 담당자가 판매 여부·구성·가격을 확인합니다.

## 핵심 결정: 구매 화면과 실제 출고 단위를 구분

고객에게 같은 `2-Pack`으로 보여도 재고 구조는 두 가지일 수 있습니다. 공개 Amazon 페이지와 ASIN만으로 어느 방식인지 확정할 수 없습니다.

| FBA의 실제 보관 방식 | Shopify 등록 방식 제안 | 재고·출고 연결 |
|---|---|---|
| 두 개가 이미 포장되어 세트 전용 MSKU로 보관됨 | 일반 상품 또는 실제 포장 단위의 variant로 등록 | 세트 1개 주문 → 세트 MSKU 1개 차감·출고 |
| 단품 재고에서 두 개를 꺼내거나 서로 다른 제품을 함께 출고함 | Shopify Bundles의 multipack/fixed bundle로 등록 | 세트 1개 주문 → 각 구성품 MSKU의 정해진 수량 차감·출고 |

**2-Pack이라는 글자만 붙인 일반 variant로 단품 재고 두 개를 자동 차감할 수 있다고 가정하지 않습니다.** 세트 전용 재고와 단품 재고를 동시에 차감하거나, 세트와 구성품을 중복 출고하지 않도록 방식은 구성별로 하나만 정합니다.

Shopify 공식 Bundles 앱은 무료이며 고정 구성과 동일 상품 묶음을 지원합니다. 주문 처리는 구성품 단위이고, 단품 가격을 바꿔도 세트 가격은 자동 갱신되지 않습니다. [Shopify 공식 안내](https://help.shopify.com/en/manual/products/bundles/shopify-bundles)

Amazon 공식 MCF 안내도 Shopify에서 만든 번들의 **구성품 SKU를 모두 Amazon SKU에 연결**하는 방식을 설명하며, Shopify Bundles 사용을 권장합니다. 이는 지원되는 연동 방식이라는 뜻이고, 현재 우리 dev에서 앱 설치·SKU 연결·출고까지 검증됐다는 뜻은 아닙니다. [Amazon 공식 설정 안내](https://buywithprime.amazon.com/knowledge-center/multichannel-fulfillment-app-for-shopify/set-up-mcf-using-the-multichannel-fulfillment-app-for-shopify)

## 고객에게 보여줄 화면

기존 상품 사진, 소개 문구, FAQ, 헤더·푸터를 유지하고 구매 영역만 확장합니다.

예: Blue Copper Peptide 상품

| 선택 카드 | 표시할 구성 | 조사 가격 |
|---|---|---:|
| Single | Serum 30 ml × 1 | $19.99 |
| 2-Pack | Serum 30 ml × 2 | $34.99 |
| Serum + Cream | Serum 30 ml + Bakuchiol Cream 50 ml | $32.99 |

- `Bundle`만 쓰지 않고 실제 포함 제품과 개수를 함께 표시합니다.
- 구성 선택에 맞춰 해당 상품 또는 번들 상품의 페이지/구매 폼을 사용합니다. 이미지·가격·품절 상태·장바구니 대상이 함께 바뀌어야 합니다.
- Shopify Bundles는 별도 상품이므로 모든 구성을 한 상품의 단순 variant로 억지로 합치지 않습니다. 고객에게는 한 그룹의 구매 선택 카드로 연결하되, 실제 주문은 올바른 Shopify 상품에 전달합니다.
- 첫 구현은 각 구성의 정상 상품 URL로 이동하는 카드 방식으로 합니다. 기존 디자인을 그대로 재사용할 수 있고 뒤로가기·새로고침·직접 링크에서도 선택 상태가 명확합니다. 이후 필요하면 페이지 이동 없는 전환을 추가합니다.
- 가격은 Shopify의 상품/variant 가격을 표시합니다. 브라우저 JavaScript에서만 할인된 금액을 계산해 결제 금액으로 사용하지 않습니다.
- 세트 수량 2개는 “세트 두 개”입니다. 예를 들어 2-Pack 수량 2 → 실제 단품 4개라는 내용이 장바구니에서 구분되어야 합니다.
- 상품 목록에는 기본 단품을 유지하고 세트 페이지를 연결합니다. 27개 판매 구성을 모두 같은 카드로 나열할지는 별도 화면 구성 결정으로 남깁니다.

## 진행 순서

1. **판매 구성 확정:** 아래 13개를 담당자가 대조합니다. 니아신아마이드 두 병 구성과 기존 단품이 동일 제품인지, Retinal 판매 재개 여부도 확인합니다.
2. **출고 방식 확정:** 각 구성이 세트 MSKU 1개인지 단품 MSKU 조합인지 정합니다. 구성품 무게와 MCF 수수료 계산 단위도 담당자에게 확인합니다.
3. **dev 최소 시범:** Copper Peptide 2-Pack과 Serum + Cream을 먼저 만듭니다. 앱이 필요한 구성이라면 dev에서 Shopify Bundles 설치를 진행하고, 소유자 본인 인증이 요구되면 대표/소유자가 직접 완료합니다. 화면 작업은 인증과 독립적으로 준비할 수 있습니다.
4. **구매 흐름 검증:** 단품↔묶음↔세트 이동, 표시가격, 장바구니, 테스트 결제, 주문 조회, 구성품 수량을 검증합니다. 합성 재고를 실제 FBA 재고처럼 취급하지 않습니다.
5. **나머지 11개 확장:** 시범 두 구성에서 확인한 구조를 재사용합니다. 추가 13개 전체가 승인표와 맞는지 확인합니다.
6. **MCF 재고 연결:** 기존에 보류된 소유자 인증·앱 설치·배송 설정 요건을 해결한 뒤 올바른 미국 FBA MSKU를 매핑합니다. 자동 출고는 꺼둔 채 재고 조회와 매핑만 확인합니다.
7. **실판매 전환 별도 결정:** 실제 결제·배송비·세금·반품정책 및 실제 출고 테스트 승인 후에만 운영 전환합니다. 테스트 주문을 실제 MCF로 보내지 않습니다.
