## 이번 구현

기존 단품 페이지 구매 영역에 구성 선택 카드를 추가한다. 카드를 선택하면 해당 세트 페이지로 이동하며 선택 상태, 실제 Shopify 가격, 구성품과 세트당 수량을 보여준다. 상품별 Shopify variant를 사용하는 기본 상품 폼으로 장바구니에 담는다. 장바구니에는 세트명, 구성품, 세트당 가격, 주문 수량과 합계를 표시한다. Products 하단에는 전체 세트 목록을 추가한다.

앱에 의존하지 않는 **독립된 테스트 세트 상품**으로 구현한다. 재고는 세트당 개발용 10개, 수동 처리, 품절 시 판매 불가다. 기존 단품 가격과 재고는 덮어쓰지 않는다. 실제 주문이나 출고는 하지 않는다.

설치 가능 여부 확인 중 공식 무료 Shopify Bundles 앱은 dev에 설치되었다. 앱 안에서는 번들을 생성하지 않았고, 이번 13개 세트의 재고·구매 동작에는 사용하지 않는다. MCF 앱과는 별개다.

## 현재 재고 방식의 한계 / 실제 출시 전 결정

이 구현은 단품 재고와 세트 재고를 공유하지 않는다. 세트 주문이 단품 재고를 차감하거나 구성품별 출고 지시를 만드는 기능은 포함하지 않는다. MCF 연결은 없음.

담당자 회신(사용자가 공유한 대화): 실제 판매·출고하는 세트는 직접 포장하여 FBA에 입고하며, 일부 가상 번들도 목록에 존재한다. 따라서 실제 포장 세트에는 현재의 별도 상품 구조를 사용할 수 있다. 단, 조사한 각 ASIN이 어느 유형인지와 MSKU는 아직 대조하지 않았다. 담당자가 전체 상품의 ASIN·SKU 목록을 보유하고 있다고 확인했으며 엑셀 전달 요청 중이다.

- 아마존에 완제품 세트 MSKU가 있다면 세트 상품을 해당 MSKU에 매핑한다.
- 단품 MSKU를 조합하여 출고한다면 Shopify Bundles 등으로 구성품 연결을 설정하고 MCF 호환을 검증한다. 이 경우 현재 독립 세트 상품을 그대로 판매하지 말고 재고 모델을 전환한다.
- 실제 Amazon Seller SKU는 아직 미확인이다. ASIN은 SKU가 아니다. `DEV-BUNDLE-*`은 개발용 임시 식별자이며 실제 MCF 매핑에 사용하면 안 된다.
- 실제 물류 모델 확인 전 이번 테스트 데이터를 운영 스토어에 가져오면 안 된다.

## 담당자에게 전달할 확인 요청

자사몰에서 아마존과 동일한 단품·2-Pack·번들을 판매하려고 합니다. 판매 중인 상품의 **ASIN ↔ Seller SKU(MSKU) 매핑 목록**을 부탁드립니다.

특히 각 2-Pack·번들에 대해 다음을 확인 부탁드립니다.

1. 세트 자체가 하나의 포장 상품으로 FBA에 입고되어 별도 MSKU와 재고를 가지고 있나요?
2. 아니면 단품 재고를 조합하는 가상 번들인가요? 이 경우 구성품별 MSKU와 필요 수량을 알려 주세요.
3. 해당 세트를 Shopify 주문에 대해 미국 Amazon MCF로 출고할 수 있는지, 세트 MSKU로 요청해야 하는지 구성품 MSKU로 나눠 요청해야 하는지도 확인 부탁드립니다.

가능하면 Seller Central의 SKU·ASIN·재고가 포함된 목록과 번들 구성표로 전달 부탁드립니다. ASIN이 있다는 것만으로 별도 포장 재고를 가진 것으로 간주하지 않습니다.
