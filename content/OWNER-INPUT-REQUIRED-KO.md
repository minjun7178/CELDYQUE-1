# 추가 확인 목록 — 기존 자료 재검토 후

업데이트: 2026-10-13. 내부 참고 목록입니다. 사용자가 카탈로그 기준의 최종 반영과 배포를 승인했습니다. 진행 상태는 `../docs/deployment-2026-10-13.md`를 확인하세요.

후속 사용자 확인: “자료대로 진행하면 될 것 같아. 현재 판매 라벨과 같아.” 기존 제품명·함량 및 현재 원고의 기존 자료 기반 표기는 유지합니다. 현재 라벨과 기존 자료의 일치 여부를 다시 요청하지 않습니다. 아래 세부 구성·문서 간 차이는 향후 설명을 확장하거나 카탈로그를 정정할 때 참고할 항목이며, 사용자가 모든 INCI·원료 순도·상충 문구를 개별 검증했다고 기록하지 않습니다.

## 함량 설명도 이미 있는 부분을 유지합니다

- **Volufiline 100%:** 기존 FAQ에 원료를 농축 포뮬러로 사용한다는 의미이며 순수 sarsasapogenin 100%가 아니라고 명시돼 있습니다. 이 설명을 복구했습니다.
- **PDRN 12% 세럼:** 기존 본문은 120,000 ppm PDRN complex로 설명하며 Sodium DNA와 phyto PDRN을 언급합니다. 복합 원료 기준이라는 설명은 보유하고 있습니다. 구성 원료의 정확한 명칭·세부 비율까지 확인된 것은 아닙니다.
- 나머지 제품도 기존 %·ppm 표기는 보유하고 있습니다. 수치가 있다는 것과 완제품의 순수 유효 성분 함량임을 입증하는 것은 별개입니다. 정의가 없는 경우 순도나 효능 우열을 덧붙이지 않습니다.

## 실제로 추가 확인할 항목

1. **ArbutXA 함량 — 해결:** 사용자 지정 카탈로그 24–25쪽에 따라 Arbutin 5% + Alpha-Arbutin 2% + Tranexamic Acid 5% + Niacinamide 2%를 원고·본문·FAQ·메타 설명·구조화 데이터에 반영했습니다. 기존 7% 합산 표기는 사용하지 않습니다.
2. **클렌징 오일 식물 성분 — 판단 정정:** 사용자가 카탈로그를 기준으로 진행하도록 지정했습니다. 8쪽은 병풀·티트리·녹차·LHA, 9쪽은 병풀·어성초·티트리·LHA를 소개합니다. 두 페이지는 전성분표가 아닌 주요 성분 소개이므로, 소개한 성분이 다르다는 것만으로 모순·오류라고 볼 수 없습니다. 카탈로그에 녹차와 어성초가 각각 기재돼 있다는 사실을 기준으로 삼으며, 기존 사이트의 쑥 표기를 추가하지 않습니다. 이 차이 자체를 배포 보류 사유로 삼지 않습니다. 정확한 전체 INCI나 함량은 이 요약으로 추정하지 않습니다.
3. **PDRN 세부 구성:** 12% 세럼의 complex 구성·phyto PDRN의 INCI, 크림과 25% 제품의 함량 정의. 세럼의 정의를 다른 두 제품에 자동 적용하지 않습니다.
4. **전성분표와 버전:** 현재 자료는 주요 성분 요약입니다. 전체 INCI와 최신 라벨은 아직 없으며, 판매 제품이 기존 자료에서 바뀌었다면 변경 부분만 전달해주세요.
5. **카탈로그 편집 오류:** 19쪽의 레티놀 제품명·레티날 설명, 23쪽의 PDRN 크림 제품명, 나이아신아마이드의 녹차/티트리 차이는 수정 대상입니다.
6. **추가 강조를 원할 때만:** Spicule 300의 의미, 펩타이드 9종/12종 구성, 원산지·비건·무향·인증 근거. 없으면 해당 설명을 생략할 수 있습니다.

## 효능 문구 작성 방식

완제품 시험 자료가 없다는 사용자 설명을 반영했습니다. 새 시험 자료를 필수로 요청하는 대신, 확인한 성분 논문·원료사 자료를 근거로 14개 제품의 성분 설명을 작성했습니다. 출처는 `ingredient-research.json`, 영어 문장은 `copy/en/products/*.md`의 `Ingredient research`에 있습니다.

- 성분 연구의 대상·제형·농도·투여 경로와 근거 수준을 구분합니다.
- 세포 실험을 사람에게 바르는 제품의 효과로, 주사 연구를 화장품의 효과로 옮기지 않습니다.
- 타 제품의 개선률·기간을 CELDYQUE 제품의 결과로 쓰지 않습니다.
- `clinically proven`, 시술 후 회복, 발모, 보장된 볼륨 증가 등 완제품 근거가 필요한 문구는 추가하지 않습니다.
- 공개 페이지에도 성분 설명과 출처를 표시하고, 구조화 데이터에는 같은 페이지의 출처 링크만 연결합니다. 임상시험·리뷰·효능 인증을 만들어 넣지 않습니다.
